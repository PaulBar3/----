# 🍗 Курица-Гриль — Сайт для производства

Современный веб-сайт для вашего производства куриц-гриль с удобной админ-панелью для управления товарами и загрузки фото.

## 🚀 Быстрый старт

### Требования
- **uv** — современный пакетный менеджер для Python
- **Python 3.13+**

### Установка

1. **Установите uv** (если ещё не установлен):
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

2. **Установите зависимости**:
   ```bash
   uv sync
   ```

3. **Запустите сервер**:
   ```bash
   ./start.sh
   ```
   Или вручную:
   ```bash
   uv run uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```

4. **Откройте в браузере**:
   - Сайт: http://localhost:8000
   - Админка: http://localhost:8000/admin

## 🔐 Доступ к админке

- **Логин**: `admin`
- **Пароль**: `admin123`

> ⚠️ **Важно**: Смените пароль в production! (файл `main.py`, строки ~63-64)

## 🔧 Настройки

### Изменить пароль админа
Откройте `main.py` и найдите строки:
```python
ADMIN_USER = "admin"
ADMIN_PASS = "admin123"  # Поменяй на свой пароль!
```

### Изменить порт
В `start.sh` или при запуске укажите нужный порт:
```bash
uv run uvicorn main:app --host 0.0.0.0 --port 8080 --reload
```

## 📝 Дальнейшее расширение

Проект легко расширять:

1. **База данных**: Замените SQLite на PostgreSQL в `main.py`
2. **Авторизация**: Добавьте JWT или сессии
3. **Оплата**: Подключите платёжную систему
4. **Доставка**: Добавьте расчёт стоимости доставки
5. **Telegram-бот**: Используйте тот же backend для бота
6. **API**: FastAPI автоматически создаёт OpenAPI документацию по адресу `/docs`
